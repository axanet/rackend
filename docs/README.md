# Maintainer documentation

The user documentation (guides, running rackend, reference) lives on the website, <https://rackend.axanet.ch/docs/>, and its source in [rackend-homepage](https://github.com/axanet/rackend-homepage) (`src/content/docs/docs/next/` describes this repository's `main`).

This folder holds what maintainers need:

- [adr](adr): architecture decisions;
- [threat-model.md](threat-model.md): the threat model;
- [performance.md](performance.md): measurements behind the quality attributes.

`errors.md` and `deployment.md` only forward links that rackend 0.0.x sends to the website.
